# 05. 앱카드 UI/UX 지침 (HubSpot 포털 패턴 기준)

기준일 2026-11-27 · 대상 : Suprema Order - HelloDigital 앱카드 전체

## 1. 분석 근거

### 1-1. HubSpot 공식 디자인 패턴 (developers.hubspot.com)
- 버튼 : 한 화면(카드·모달·패널)에 primary 1개. primary+secondary 또는 destructive+secondary만 짝. **왼쪽 정렬, primary가 왼쪽**. 오른쪽 정렬은 다단계 이동 버튼만. 기본 크기, 좁은 표 행만 xs.
- 표 : 비교·상세 데이터에만 사용. 행 버튼은 그 행에 직접 관련된 것만, `xs`·`secondary`, 오른쪽 정렬. 긴 내용은 행에서 Panel로.
- 마켓플레이스 품질 기준 : primary 1개, destructive는 삭제류에만, 링크 옆 밑줄 텍스트 금지, **Tag를 버튼·링크 대신 쓰지 않음**.
- 레코드 화면 : 카드·탭에 속성 조건(조건부 로직) 지정 가능, 탭은 개요 포함 최대 5개.

### 1-2. 포털 기본 카드 관찰 (거래 레코드)
| 기본 카드 | 관찰된 패턴 |
|---|---|
| 연결 카드(회사·연락처) | 제목 옆 개수 `(2)`, 오른쪽 `+ 추가`. 레코드마다 테두리 타일: 이름 링크(미리보기) → 라벨: 값 3~4줄 → 연결 라벨 태그. 하단 `모두 보기 ↗` |
| 빈 카드(견적 등) | 설명 1줄 + 가운데 secondary 버튼 1개 |
| 속성 카드(About this deal) | 라벨 위·값 아래, 빈 값 `--` |
| 단계 트래커 | 가로 막대 1줄 + 현재 단계 태그 |
| 공통 | 카드 제목은 HubSpot 머리글이 표시 → 본문에서 제목 반복 없음. 하단에 "~에 의해 구동됨" 자동 표시 |

## 2. 사용성 지침 (분류)

| 분류 | 지침 |
|---|---|
| G1 구조 | 본문에서 카드 제목·앱 이름 반복 금지. 맨 위 = 상태 줄(상태 태그 + 한 줄 설명), 맨 아래 = 버전·새로고침 한 줄 |
| G2 정보 표시 | 연결 레코드는 기본 연결 카드와 같은 타일(이름 링크 → 핵심 값 → 보조 정보). 값 없는 항목은 숨김(표 셀만 `--`). 같은 의미 태그 반복 금지 |
| G3 행동·버튼 | 화면당 primary 1개, 왼쪽 정렬. 레코드별 동작은 `⋯` 메뉴(Dropdown) 1개로 모음. 이름 클릭 = 미리보기. 삭제·해제는 확인 후 실행 |
| G4 상태·피드백 | 모든 상태를 태그 1개로 구분(대기·가능·완료·없음·오류). 로딩은 스피너 1개, 저장 후 결과는 상단 알림 대신 상태 줄 갱신 + 토스트(addAlert) |
| G5 문구·언어 | HubSpot UI가 한국어일 때만 한국어. 안내는 "~없습니다 / ~불가합니다 / 필요한 조치 : ~하세요." 라벨 "영문(한글)" |
| G6 노출 조건 | 카드가 쓸모없는 레코드에는 카드 자체를 숨김(레코드 화면 조건부 로직). 코드 안 "사용 불가" 안내는 최후 수단 |
| G7 폭 대응 | 가운데 = 표·2단 허용, 사이드바 = 1열·표 금지·긴 입력은 Panel |
| G8 성능·동기화 | 카드 간 값은 `hd_card_sync`로 즉시 새로고침. 같은 데이터는 한 번에 불러오기 |

## 3. 앱카드 개선 방향

| 카드 | 문제 (11/27 화면) | 개선 |
|---|---|---|
| End Customer (가운데) | 제목·버전 문장 반복, 레코드당 버튼 4개, 빈 값 다수, "End Customer" 태그 반복, 하단 2줄 | 상태 줄 + 회사 타일 + 담당자 표(행 `⋯`), 편집은 한 화면, 하단 1줄 |
| End Customer (사이드바) | 가운데와 정보량 동일, 버튼 다수 | 회사 1줄 + 담당자 이름·직책 목록, 편집 = Panel |
| 영업기회 전환 (가운데) | 6단계 원형 스텝, 큰 안내·완료 상자, Opportunity에서 "사용 불가" | 상태 줄 + 3단계 문구, 숫자 요약 4개 + 접힌 상세, 완료 = 결과 타일, Opportunity에서는 원본 Lead 표시 |
| 영업기회 전환 (사이드바) | 안내 문장만 | 상태 태그 + 결과 링크 / 만들기 버튼 |
| 공통 | 버튼 오른쪽 정렬 | 왼쪽 정렬, primary 왼쪽 |
